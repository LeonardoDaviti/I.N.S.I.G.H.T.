# 0024 — Release updates: new versions of the apps and services I use

Status: **future** (owner, 2026-10-27).

## The owner's wish
Know when the apps and services I use ship a new version — GitHub repositories, and also apps like Obsidian and other services — without checking each one.

## Notes for later
- **GitHub repositories:** `https://github.com/<owner>/<repo>/releases.atom` is a plain Atom feed and already works as an RSS source today; a template ("GitHub releases: owner/repo") would make it one click.
- **Apps outside GitHub:** many publish a changelog page, a blog feed or a release RSS (Obsidian's changelog, for example). Each needs checking: a feed when there is one, otherwise a small site adapter like pipecraft's (0018).
- **Reading:** releases are short and frequent; they may want their own place (a "Releases" track or view) rather than mixing into the main feed.
- Related: 0023 (GitHub Trending, built first).
